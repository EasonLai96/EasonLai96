## ✨ 重點展示：Folia for Android

**讓歌詞成為風景，把 Folia 的沉浸式聽歌體驗帶到手機。**

基於 [Folia](https://github.com/chthollyphile/folia-major) 的社群非官方 Android 移植，使用 Capacitor 打包成可直接安裝的 APK。我主要負責 Android 整合與手機體驗調整；核心播放器、歌詞動畫與視覺設計來自上游團隊。

- **直接安裝**：提供 APK，不用自行部署，也能改用自己的後端。
- **系統媒體控制**：通知欄、鎖屏與相容機型的 HyperOS 超級島整合。
- **手機操作**：迷你播放條、左右滑動切歌、下滑離開播放頁。
- **沉浸式展示**：輕點收起操作介面，保留歌詞動畫畫面。
